# CourtDay เฟส 1

เว็บแอปจัดแข่งแบดมินตันสำหรับผู้จัดที่เช่าใช้ ไม่ต้อง build ใช้ HTML + JavaScript ล้วน เชื่อม Supabase ตรง

## โครงสร้าง
- `supabase/migrations/001_courtday.sql` ตาราง, RLS, ฟังก์ชันสมัคร/ชำระเงิน/คิดคะแนน, บักเก็ตรูป
- `web/` หน้าเว็บทั้งหมด (โฮสต์เป็นไฟล์สถิตที่ไหนก็ได้ เช่น Cloudflare Pages, Netlify, Vercel)

## ติดตั้ง
1. สร้างโปรเจกต์ Supabase แล้วรัน `001_courtday.sql` (SQL Editor หรือ CLI)
2. Authentication > Providers > Email: ตั้งว่าจะบังคับยืนยันอีเมลหรือไม่
3. แก้ `web/js/config.js` ใส่ Project URL กับ publishable key
4. อัปโหลดโฟลเดอร์ `web/` ขึ้นโฮสต์สถิต
5. Authentication > URL Configuration: ใส่โดเมนเว็บเป็น Site URL

## โฟลว์
ผู้จัดสมัครบัญชี > สร้างรายการ > ตั้งประเภท/ค่าสมัคร/PromptPay > เปลี่ยนสถานะเป็น "รับสมัคร"
ผู้เล่นสมัคร (พิมพ์ชื่อคู่เอง ไม่มีลิงก์เชิญ ลิงก์วิดีโอไม่บังคับ) > สแกน QR จ่าย > แนบสลิป
ผู้จัดตรวจสลิป/ดูวิดีโอ ย้ายรุ่นได้ > ยืนยัน > สร้างสาย > จัดตาราง > ให้คะแนนสด

## ยังไม่ได้ทำ (เฟสถัดไป)
- แจ้งเตือน LINE
- ลิงก์/QR กรรมการแยกต่อคอร์ต (ตอนนี้ต้องล็อกอินเป็นผู้จัด)
- แบ่งกลุ่มแล้วต่อน็อกเอาต์ในประเภทเดียว (ตอนนี้เลือกแพ้คัดออกหรือพบกันหมด)
- ลบสลิปอัตโนมัติหลังจบรายการ 90 วัน (pg_cron)
- จำกัดอัตราการสมัคร/captcha กันสแปม
- แพ็กเกจและโควตาพื้นที่ต่อผู้จัด, เกียรติบัตร PDF, โหมดจอ TV เต็มจอ
